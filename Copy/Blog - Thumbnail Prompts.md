# Blog Thumbnail Prompts

Paste-ready prompts for generating blog thumbnails (GPT image gen, or any tool). Every
thumbnail shares one visual system so the blog index looks like a deliberate family: a matte
charcoal surface, vast negative space, and a single muted burnt-coral accent. One metaphor
per post.

---

## The shared visual system (applies to all)

- **Surface:** smooth matte dark charcoal, near-black (#0c0c0c), like fine cast concrete or slate
- **Accent:** a single muted burnt-coral (#e75534). Refined and elegant. Never molten lava, never fiery, never neon-bright.
- **Light:** soft directional studio lighting, a subtle cool-grey gradient fading toward one corner
- **Feel:** calm, refined, architectural, high-end, editorial. Lots of negative space, soft shadows, fine micro-texture, deep cinematic depth of field.
- **Always:** no text, no logos, no people. 16:9 widescreen.

### Global settings (do this every time)
- Export **16:9**, clean crop (around 1200x630 for the social/OG card). Tell GPT to avoid dark padding bars.
- Generate **textless**. The title goes on in Webflow, in your grotesk with the coral accent word, matching the case-study cards.
- If the coral comes out too red/bright, nudge the hue toward **#e75534** and drop the glow's brightness ~15% in Figma/Photoshop. The accent is always one isolated element, so this is a 30-second fix.
- If a result comes back jagged, chaotic, or molten, reply in the same chat: *"keep everything identical but make it cleaner, finer, calmer, and the glow a softer burnt-coral, less red, less bright."* Iterating on the existing image beats regenerating.
